CON-03Admin console

Server administration

Install a dedicated server, load our mods, set them up from the profile files and drive them with in-game commands. Everything here is generic: no real server, address, port or password.

011. Install a dedicated server

  1. Install Arma Reforger Server (Steam tool, or SteamCMD with app ID 1874900), or rent a game server from a host.
  2. Write a configuration file, for example server.json (structure below).
  3. Start the server with -config pointing to that file and -profile pointing to a folder it can write to. That folder is what our mods call $profile:.
  4. Add our mods to game.mods: each mod page gives the full block ready to paste, and the scenario ID to put in game.scenarioId.
  5. Start once, stop, then drop our config.json files into the profile folder (section 4) and start again.

022. Generic server.json

The usual structure of a Reforger dedicated-server configuration. Fill in your own values; ports shown are the documented defaults. Keep passwordAdmin out of any file you share.

game.gameProperties.persistence.autoSaveInterval sets the autosave interval (minutes). The persistence block belongs inside gameProperties: at the root or directly in game, the server refuses to start.

044. Profile files

  • $profile: is the folder given to the server with -profile. A file named $profile:INDFORGE_Weather/config.json lives in <profile>/INDFORGE_Weather/config.json.
  • A missing file is created with its defaults at startup. An existing file is never overwritten: to take a new default, put the reference copy back.
  • Every key Name comes with a help key _Name right above it. The mod never reads help keys: they are there for you, and can be deleted.
  • Most files are read once at startup: restart the server after a change. Never edit a file while the server writes to it.
  • Do not delete a key to "go back to default": the code fallback is not always the shipped value. Copy the original value back instead.
